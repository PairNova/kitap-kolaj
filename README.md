# kitap-kolaj

Kitap seti ilanları için üretilen **kolaj görselleri**.

Bu depo yalnızca görsel barındırır. İçinde iş verisi, fiyat, maliyet, reçete
ya da müşteri bilgisi **yoktur**.

Görseller, Hepsiburada'nın herkese açık ürün sayfalarındaki kitap kapaklarından
üretilmiştir. Hepsiburada içe aktarım sırasında görselin kopyasını kendi CDN'ine
aldığı için, buradaki dosyalar yükleme tamamlandıktan sonra silinebilir.
